# RedLine 4.5

https://stilltripsih.github.io/redline/

Касание отметки выбирает промежуток на спирали и показывает список под ней. Лупы больше нет. Белый короткий маркер — текущее время, оранжевые отметки — события. Центр всегда показывает глобальное событие, а таймеры — своим списком.

Начало запланированных событий сопровождается отдельным коротким сигналом; конец таймера — длинной мелодией. Дедупликация и ограничения позднего проигрывания исключают повтор и поток старых сигналов.

Спорт и часовая разминка: иллюстрированный пятиминутный офисный комплекс. Шея, плечи/грудной отдел, мягкий поворот верхней части корпуса и ходьба. SVG-схемы и короткие инструкции доступны в событии и при отсчёте; шаги переключаются по времени. Совпадающие офисные режимы не создают две одинаковые паузы. Это общий набор движений для смены позы, не лечение заболеваний позвоночника.

Источники: https://www.nhs.uk/live-well/exercise/sitting-exercises/ · https://www.hse.gov.uk/msd/dse/work-routine.htm
