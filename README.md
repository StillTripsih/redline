# RedLine 3.8

https://stilltripsih.github.io/redline/

Главный экран закреплён. День — одна непрерывная спираль в два оборота от 0 до 24 часов, рабочие часы выделены толщиной. При любом таймере спираль становится серым фоном, её область и центр не меняют положение.

Две нижние иконки открывают точные настройки таймера и секундомера: часы, минуты, секунды выбираются колёсиками. Секундомер поддерживает необязательную цель со звуком, паузу/продолжение, сброс и круги. Время паузы исключается из отсчёта, сохранённой длительности и статистики. Настройки быстрых целей сохраняются. Категории для них не нужны.

Сигнал окончания планируется в AudioContext при запуске, без нажатия подтверждения. При отмене, сбросе и паузе план отменяется; при продолжении назначается заново. Окончание не дублируется по кнопке завершения. Тест звука через HTML Audio сохранён. Системное ограничение фонового звука на телефоне не проверено.

Адрес, redline_v3, история, настройки и активные таймеры сохраняются. Перед записью создаётся before_38 без удаления предыдущих копий. Переустановка не нужна. 39 автоматических тестов; интерфейс и физический звук на телефоне не проверялись.
