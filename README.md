# RedLine 4.1

https://stilltripsih.github.io/redline/

Широкие полосы спирали WORK/SLEEP/AWAKE (48–56 единиц в SVG 500×500), значки пауз внутри; витки разделены зазором. В центре — ближайшее событие и время до него, нажатие открывает экран «События».

События: рабочие часы, сон, свободное описание работы/нагрузки/пожеланий, включение и интервалы глаз/разминки/воды. Данные сохраняются локально.

По кнопке AI получает рабочие данные, рабочие часы/сон, настройки событий и сводку пауз за неделю. Личный API подключается существующим экраном. Ответ проходит проверку допустимых изменений, показывается предварительный план WORK/SLEEP и правила событий. Применение — отдельной кнопкой, без изменения истории или API-ключа. Запрос расходует квоту пользователя; реальный запрос с личным ключом не проверялся.

Таймеры, сворачивание, звуки и история сохранены. before_41 перед первой записью. UI и звук на телефоне не проверялись в этой версии.
