# RedLine 3.9

https://stilltripsih.github.io/redline/

Большая спираль суток; рабочие часы толще, сон отмечен отдельно (23:00–07:00 по умолчанию, меняется в настройках). В активной сессии спираль серая, центральный круг крупнее, положение циферблата постоянно.

Секундомер стартует одним нажатием без выбора длительности, сохраняет паузу/продолжение/сброс/круги. Настройка таймера — часы/минуты и мелкие секунды, запуск галочкой справа внизу. Крестики, галочки и назад без круглых подложек. Из статистики назад ведёт на главную, верхний общий счётчик скрыт.

Один HTML Audio повторно используется после старта по нажатию. Автоматическое окончание отправляет настоящий запрос воспроизведения; предположение о слышимости заранее запланированных осцилляторов больше не подавляет сигнал. Timeout и tick дедуплицируются по id; Web Audio — запасной путь. Ограничения фонового воспроизведения и физическая слышимость на телефоне не проверены.

Адрес и redline_v3 сохранены; before_39 добавляется перед записью. Переустановка не нужна.
