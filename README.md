# RedLine

https://stilltripsih.github.io/redline/ · версия 3.7

Один большой циферблат и два концентрических кольца. Активная половина дня снаружи с иконками пауз, неактивная внутри приглушена и использует точки. В 12:00 и 00:00 роли меняются автоматически. Рабочие интервалы выделены на обоих кольцах. В центре — отсчёт от фактических timestamp; секунды показаны компактно, текущее положение обновляется между тиками.

В активной паузе/зарядке/отсутствии цифры остаются в центре циферблата. Отличаются значок, фон, цвет и индикатор прогресса. Кнопки завершения и отмены под циферблатом.

Настройки разделены на компактные сворачиваемые карточки. Версия и обновление находятся сверху. Подключение Google AI сведено к API-ключу, ссылке https://aistudio.google.com/apikey и проверке. Ранее подключённые API не отключаются; ключ хранится отдельно от истории. Команды/советы находятся в сворачиваемом разделе.

Адрес, redline_v3, история и активные таймеры сохраняются, перед первой записью добавляется before_37 без удаления предыдущих копий. Переустановка не нужна.

33 автоматических теста и синтаксические проверки пройдены. Проверки звука/API используют имитацию; настоящий телефон, браузерный UI и личный API-ключ не проверялись.

3.7: неподвижный главный экран, скрытые полосы прокрутки, внешняя орбита иконок, круговой прогресс пауз. Звуковая проверка через HTML Audio с WAV-сигналом и fallback Web Audio; сообщение о статусе не подтверждает физическую слышимость.
