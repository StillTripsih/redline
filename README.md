# RedLine 4.0

https://stilltripsih.github.io/redline/

Толстая спираль суток с отдельными цветом/толщиной зонами WORK, SLEEP, AWAKE и подписями по линии. Сон по умолчанию 22:00–06:00; прежнее значение по умолчанию 23:00–07:00 заменяется, другие пользовательские интервалы сохраняются. Крупная стрелка реального времени; значки полезных пауз внутри спирали.

Отсчёты используют общий полноэкранный слой: очень крупные тонкие белые цифры на полупрозрачном красном градиентном круге без обводки; главный экран размыт и затемнён. Свернуть возвращает к главной странице и не завершает отсчёт. Под спиралью постоянная строка с живым временем, развернуть, пауза/продолжение и отмена.

Быстрый таймер: 3, 5, 10, 15 минут и плюс для своих вариантов; свой вариант сохраняется после запуска. Пользовательский выбор через колёсики с иконками, минуты красные, секунды второстепенные. Секундомер стартует без выбора времени.

При обновлении один раз устанавливаются запрошенные звуки: только завершение. Остальные события можно включить вручную в звуках. Значок звука в настройках переключает общий mute с красной перечёркнутой иконкой, нажатие на название открывает подробные настройки. Удлинённая мелодия завершения — около 3.8 секунды. Используется подтверждённый пользователем повторный HTML Audio.

Всплывающие сообщения удалены; ошибки ввода показываются внутри открытого меню. Адрес, redline_v3, история и настройки сохранены; before_310 создаётся перед записью. Свернутый режим внутри приложения поддерживается; фон закрытого/заблокированного телефона не проверен. Реальный UI и слышимость новой версии не проверялись.
