# RedLine 4.4

https://stilltripsih.github.io/redline/

Лупа 3x, диаметр128 SVG, отнесена от пальца на120. Возле события показывает крупную иконку и название; нажатие открывает данные/запуск на той же странице. Главные иконки без кругов. Центр всегда про глобальное событие, таймеры и секундомеры отдельным списком.

Режим включается и выключается повторным нажатием, сразу сохраняется; все режимы можно выключить. Карточка: цель/описание, «во время работы / свободное время / весь день», удалить слева, сохранить галочкой справа. 100 повторений за 3 подхода распределяются 34+33+33; AI-план проверяет сумму и число подходов перед применением. Лекарства не назначаются AI.

При обновлении один раз восстанавливается запрошенный исходный режим с07:00: ежечасная разминка/растяжка, 2 перерыва вода/чай. Следующее выключение сохраняется. История/таймеры/API сохранены, before_44.

Gemini API: поле16px не должно вызывать автоматический zoom iOS; ограничена ширина. Случайные пробелы/кавычки убираются. Поддерживается ввод стандартных и auth-ключей без отбрасывания по префиксу. Два этапа проверки, пробная генерация, явное «Подключено и сохранено» с моделью/временем только после успеха. Ошибки Google показываются с HTTP/reason без раскрытия ключа; старый ключ сохраняется при неудачной замене. Из режима есть прямой переход к подключению.

Документация Google проверена: https://aistudio.google.com/docs/api-key · новые auth-ключи и ограниченные стандартные ключи поддерживаются сервером Google, неограниченные стандартные отклоняются. Причина ошибки конкретного пользовательского ключа без проверки не установлена.

64 автоматических теста пройдены. Реальный UI/лупа/автозум/личный ключ/заблокированный телефон не проверялись.
