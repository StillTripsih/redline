# RedLine 4.2

https://stilltripsih.github.io/redline/

Единая спираль 0–24: все полосы толщиной 36, шаг витка 72 и чистый промежуток 36 SVG единиц. Короткая поперечная отметка нынешнего времени (44), числа каждого часа и четвертьчасовые деления вдоль спирали. Полезные паузы отмечены белыми штрихами. WORK/SLEEP/AWAKE разделяются цветом. Центр открывает настройки событий и персональный AI-план.

Можно запустить два независимых таймера/секундомера (quick/extraQuick). Текущая полезная пауза отдельно. После сворачивания приложение доступно для других действий; под спиралью список таймеров с живым временем, паузой/продолжением, отменой и повторным открытием. Раскрытый отсчёт: свернуть, отменить, подтвердить в одном ряду. Ручная галочка не проигрывает завершение.

Сигнал окончания только при достижении deadline, независимо от открытого экрана. Повторный HTML Audio сохранён; при одновременном окончании сигналы разнесены. По умолчанию только end, остальные события доступны в настройках. Настоящий фон закрытого/заблокированного телефона не проверен.

Прошлые данные и origin сохранены, before_42. 50 автоматических тестов. Новый интерфейс и слышимость на телефоне не проверены.
