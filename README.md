# RedLine

Локальный помощник рабочего дня. Адрес: https://stilltripsih.github.io/redline/.

## Версия 3.4

Главная: 12-часовой циферблат, рабочее расписание и круглые действия. Три верхних значка открывают звуки, общие настройки и статистику. Название/версия и кнопка обновления находятся в общих настройках.

Звуки: общая громкость, тембр, отдельные события и прослушивание. Настройки: основные цвета, интервал работы, напоминания, редактирование/порядок/длительность видов перерывов и добавление собственных. Статистика: день/период, перемещение и масштабирование графика, выбор дня и журнал всех сохранённых событий. Новые быстрые и отменённые таймеры также записываются в журнал.

Сохраняются прежний адрес, localStorage redline_v3, история и активные таймеры. Дополнительная копия перед первой записью этой версии: redline_v3_before_34; прежние копии не удаляются. Переустановка не требуется.

Звуки используют Web Audio после взаимодействия. Фоновые сигналы/блокировка телефона и реальные жесты на телефоне не проверены.

Проверки: node --test core.test.mjs; node --check app.mjs; node --check panels.mjs.
