# RedLine 4.6

https://stilltripsih.github.io/redline/

Умный трекер привычек с режимами под рабочий день, отдельными таймерами и сохраняемыми напоминаниями.

При наступлении события появляется окно привычки с повторяющимся сигналом: Начать, Выполнено, Позже5мин, Отменить, Выключить звук. Очередь и отложенные сроки сохраняются локально. Выключение звука закрывает текущее окно, оставляя напоминание доступным через значок; новое событие вновь уведомляет. Режимы с выключенным выбором не продолжают звонить. Выполнение/пропуск отмечаются в истории.

Спираль плавно гасит прошедшие30мин и сосредоточена на ближайших12часах; следующая дата поддержана. Центральное глобальное событие отдельно от списка независимых таймеров.

Повторный audible loop работает через отдельный разрешённый аудиоплеер; mute и громкость пользователя соблюдаются. Независимые таймеры продолжают идти. В закрытом или заблокированном браузере операционная система может остановить приложение: системный будильник не гарантируется. Данные напоминаний сохраняются и доступны после возвращения.

77 автоматических тестов. Origin, история, режимы, API и таймеры сохранены, before_46. Телефон/реальная слышимость/браузерный UI не проверены.
