# RedLine

Рабочий день, перерывы, зарядка и секундомер отсутствия. Публикуется на https://stilltripsih.github.io/redline/.

Версия 3.3 сохраняет прежний ключ localStorage redline_v3 и действующие записи/таймеры. Перед первой записью создаётся локальная копия прежнего содержимого redline_v3_before_33. При ошибке чтения исходное хранилище не перезаписывается.

Кнопка обновления перезагружает текущий адрес без переустановки. Звуки используют Web Audio после взаимодействия с приложением; сигналы в фоне и на заблокированном телефоне не проверены и не гарантируются. История и таймеры восстанавливаются по сохранённым отметкам времени.

Проверки: node --test core.test.mjs; node --check app.mjs.
