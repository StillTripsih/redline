# RedLine

https://stilltripsih.github.io/redline/ · версия 3.5

Два круга показывают первую и вторую половину дня, рабочие интервалы выделены. Отметки воды, разминки и глаз пересчитываются от фактического завершения паузы. Интервалы, длительности и отключение каждого вида доступны в настройках. Исходные ориентиры: разминка после примерно 55 минут и отдых глаз 20 секунд после 20 минут; вода — настраиваемое напоминание без рекомендации объёма. Источники: https://www.hse.gov.uk/msd/dse/work-routine.htm и https://www.aao.org/eye-health/diseases/what-is-eye-strain.

Настройки слева, статистика справа, дата и рабочие часы в одной строке. Звуки перенесены в настройки. Если Web Audio не готов при завершении, сигнал сохраняется до попытки разблокировать звук после взаимодействия/возвращения. Режим системной тишины и фоновая работа остаются ограничениями устройства; на телефоне не проверено.

AI: Gemini, OpenAI и совместимый Chat Completions API с собственным HTTPS-адресом. Личный ключ проверяется тестовым запросом и хранится отдельно redline_ai_connection, только после успеха. Для CORS-ограниченных API нужен совместимый сервер/прокси. По явному нажатию отправляются агрегат пауз, выбранный период, цели и команда. ИИ предлагает изменения; применяются только после отдельного нажатия и локальной проверки. История не может быть удалена ответом ИИ. Никаких фоновых AI-запросов.

Сохраняются прежний origin, redline_v3 и история. Перед первой записью сохраняется снимок redline_v3_before_35, старые снимки не удаляются. Переустановка не нужна.

Проверка: node --test core.test.mjs; node --check app.mjs; node --check panels.mjs. Тесты звука и API используют имитацию аудиоконтекста/ответов, а не реальный телефон или оплаченный запрос провайдеру.
