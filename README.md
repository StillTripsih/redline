# RedLine 4.3

https://stilltripsih.github.io/redline/

Режимы: разминка каждый час (по умолчанию), спорт, растяжка, лекарства, питание, свой. Каждый режим редактируется, включается, удаляется и сохраняется. Интервалы рабочего режима привязаны к выбранным рабочим часам и фактическому окончанию движения. Спорт/растяжка могут назначаться после работы или пробуждения, в фиксированное время, по дням недели.

Сон и окна питания предлагаются как удобный распорядок, редактируются/применяются пользователем. Поддержан ночной график. Лекарства — только напоминание по вручную введённому назначенному времени; AI их не назначает/не меняет. AI получает рабочий контекст, часы и режимы без лекарств, сводку пауз по нажатию; результат сначала проверяется и показывается перед применением.

Спираль: оранжевая WORK, светло-оранжевые штрихи пауз с прямыми краями на всю полосу, белый короткий маркер настоящего времени. Лупа увеличивает участок в 2 раза при перетаскивании; события рядом показываются строкой с отличием совета от плана. Поддержаны клавиши. Центр всегда показывает глобальное событие, независимые таймеры — только списком ниже. Таймер и секундомер имеют разные значки/подписи, «Отойти» — значок.

57 автоматических тестов. Данные/адрес сохранены, before_43. Реальные телефон, лупа, UI и личный AI API не проверены.

Источники общего подхода: https://www.hse.gov.uk/msd/dse/work-routine.htm · https://www.cdc.gov/sleep/about/ · https://sps.nhs.uk/articles/reminding-to-take-medicines-supporting-adherence/
